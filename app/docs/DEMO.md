# Демо-сценарий «Улыбки» (сцена, ~4 минуты)

Правило из ТЗ: на сцене только проверенное. Прогнать этот сценарий руками накануне
и утром — города покрытия меняются, инвентарь живой.

## Подготовка (за 30 минут до выхода)

1. `.env`: ключ OpenRouter (умный ввод) и Mapbox-токен (карта) на месте.
2. `go run ./cmd/smile` → http://localhost:8080, в шапке «MCP: N выз».
3. **Прогреть кэш**: создать демо-событие один раз до сцены — повторный прогон
   на сцене попадёт в TTL-кэш и соберётся мгновенно. Заодно проверить, что все
   демо-города отдают маршруты СЕГОДНЯ.
4. Не жать «перепроверить» чаще раза в пару минут: WAF Туту банит бурсты
   (breaker это переживёт, но на сцене лучше без «Туту остывает»).
5. **Чекаут-ссылки открывать с УСТРОЙСТВА, чей IP не в бане WAF.** Сервис
   ходит в MCP через прокси-пул, но клик по «дожать» идёт с IP браузера:
   если демо-машина ловила бан — ссылки с неё «не открываются» (TLS reset),
   хотя сами они валидны. Проверка: открыть www.tutu.ru в браузере; если не
   грузится — показывать чекаут с телефона (LTE) или через VPN.

## Акт 1 — Вход голосом (30 сек)

Микрофон 🎤 на главной, сказать одной фразой:

> «Свадьба в Казани пятого сентября, сбор в три часа дня. Бабушка Нина из
> Москвы, ей подешевле и нужна гостиница. Сергей тоже из Москвы, пусть едут
> вместе. Друг Артём из Питера, ему побыстрее. Дядя Витя из Калуги.»

→ «⚡ Собрать событие» → конструктор уже заполнен: имена, города, профили,
флаги ночлега и попутчиков. Ничего не печатали. Правка тоже голосом:
«добавь Пашу из Перми, летит» → черновик мёржится.

## Акт 1.5 — Гости собираются сами (30 сек)

На табло «🔗 позвать гостей» → ссылка уходит «в чат» (второй ноутбук/телефон).
Гость открывает, вписывает «Света, Уфа, побыстрее» → жмёт «Я еду» → строка
появляется на живом табло у всех на глазах, и маршрут из Уфы считается сам.
Фраза питча: «организатор больше не собирает гостей — гости собираются сами».

Дополнение словами: в строке «скажи табло» произнести «перенеси сбор на 16:00»
— табло переставит рамку и пересчитает всех.

## Акт 2 — Табло (60 сек)

«Собрать событие» → живое табло: каждому гостю маршрут ОТ ДЕДЛАЙНА НАЗАД
(питерский — ночной поезд накануне), карта, волна прибытий с зазором 20 минут.

Показ глубины (кликнуть строки):
- **Дядя Витя, Калуга**: прямых поездов нет → автобус, в логе решений видно
  переключение режима (их собственный edge-case, обработанный вживую).
- **Бабушка Нина**: блок «🛏 Ночлег» — живые отели с ценой за весь стей и
  кнопкой на чекаут Туту.
- **Попутчики**: Нина и Сергей в одном поезде + «💺 вагон N, места X и Y рядом —
  цена за двоих» — живая схема вагона РЖД (`get_rail_seatmap task=together`).

## Акт 3 — Живой инвентарь (45 сек)

Кнопка «💥 рассыпать» (честная симуляция на реальной альтернативе из последнего
живого поиска): строка вспыхивает «пересобран», в логе — «маршрут выкупили →
пересобрал на …». Если есть гость без маршрута — табло само просит помощи
фактами: «🆘 мне нужна помощь с гостем из Калуги…» (единственный случай, когда
событие говорит).

## Акт 4 — Гость дожимает (45 сек)

«📋 приглашение» → готовый текст со ссылкой. Открыть карточку гостя (это просто
ссылка, без аккаунтов):
- одна тёплая фраза + факты маршрута,
- «🎫 Дожать на Туту» — deeplink из `checkout_ref` байт-в-байт,
- гость сам меняет вариант («поеду этим») — выбор закрепляется и переживает
  перепроверки,
- «✓ я купил билет» → строка на табло зеленеет «куплен» и замораживается.

## Финал (15 сек)

Табло: N/N в сборе, обратный отсчёт. «Индустрия продаёт кресла индивидуумам —
события состоят из групп. Улыбка собирает группу и отдаёт Туту N чекаутов.»

## Ответы на ожидаемые вопросы

- **Приватность попутчиков**: только opt-in, имена раскрываются при взаимном
  согласии, до того — «с вами едет ещё один гость».
- **«Прибыл в город» ≠ «прибыл в зал»**: за это отвечает буфер организатора.
- **Покупка**: руками гостя по deeplink — автоматики не обещаем, MCP read-only.
- **Rate limits**: politeness-gate + circuit breaker; сбой сети не рассыпает
  табло (держим последнее честное состояние).
- **Где ИИ и зачем**: ввод (текст/голос/чат → событие), вайб → города-кандидаты
  (ранжируют живые цены, не LLM), человеческая фраза в карточке. Всё
  деградирует без ключа — продукт остаётся рабочим.
