# Улыбка (tutu-smile)

«Улыбка» собирает гостей события из разных городов к одному дедлайну: организатор задаёт рамки (место или свободный «вайб», дата, буфер, бюджет), сервис строит каждому гостю маршрут от дедлайна назад по живым данным Туту, держит живое табло прибытий и выдаёт гостям ссылки «дожать» на чекаут. Если маршрут рассыпается (место выкупили, цена уплыла) — строка табло пересобирается автоматически. Бесплатно; воронка в чекаут Туту.

Проект хакатона «ИИ × Туту MCP». Сайт: **https://tutu-smile.ru**. Данные: `https://mcp.tutu.ru/mcp` (JSON-RPC, без авторизации).

## Что в репозитории

- **`app/`** — приложение: Go-бинарник (stdlib + embed), оркестратор MCP-вызовов (батч, кэш, ретраи, деградация при soft-fail), LLM-слой (вайб → параметры поиска), веб-фронт с живым табло, конструктором события и join-ссылками для гостей.
- **`site/`** — лендинг: статика без сборки, split-flap табло, WebGL-свет, сгенерированные ассеты. Открывается любым статик-сервером.
- **`docs/`** — сайт документации по исходному коду (Go, `go:embed`).
- **`mcp-map/`** — снятая карта MCP Туту: плейбуки, ресурсы, тулзы (для разработчиков).

## Запуск

Приложение (нужен Go 1.26+):

```bash
cd app
cp .env.example .env   # OPENROUTER_API_KEY и MAPBOX_TOKEN — оба опциональны
go run ./cmd/smile     # http://localhost:8080 (порт: SMILE_ADDR=:8081)
go test ./...          # юнит-тесты
```

Без ключей всё работает на живом MCP; деградируют только вайб-режим (LLM) и карта.

Лендинг:

```bash
python3 -m http.server 8321 --directory site   # http://localhost:8321
```

Документация:

```bash
cd docs && go run .    # http://localhost:8090
```

## Как это устроено (коротко)

1. Организатор задаёт рамки события или рассылает join-ссылку — гости вписывают себя сами.
2. На каждого гостя: поиск мультитранспорта `origin → место`, фильтр `прибытие ≤ дедлайн − буфер`, ранжирование по профилю («дешевле»/«быстрее») и бюджету. Отвалившийся вид транспорта (soft-fail) → честное переключение на оставшиеся.
3. Табло следит за строками: перепроверка по таймеру, маршрут рассыпался → автопересборка.
4. Гость получает карточку-ссылку с кнопкой «дожать» → чекаут Туту. Покупка — руками гостя.

Подробности — в `docs/` (архитектура, API, пайплайн, фронтенд, MCP).
