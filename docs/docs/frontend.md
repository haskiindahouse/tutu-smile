# Фронтенд

Ванильный JS без сборки в `web/assets/`: `index.html` (шелл, CDN: mapbox-gl 3.9.0, qrcodejs 1.0.0), `app.js` (~1140 строк), `board.js` (~625, грузится после и вызывает `boot()`), `styles.css`. Общие утилиты живут на `window.__smile`.

## Роутер

Hash-based: `#/` (умный ввод), `#/new[?vibe=1]` (конструктор), `#/e/{id}` (табло), `#/g/{id}/{gid}` (карточка гостя), `#/j/{id}` (join-страница), `#/meet`, `#/spin` (рулетка).

`boot()` тянет `/api/config` (Mapbox-токен, список городов в `<datalist id="cities">`). `refreshHealth()` каждые 15 с опрашивает `/healthz` и показывает пилюлю «Туту остывает…» при открытом breaker.

## Умный ввод

Textarea с дебаунсом 1200 мс и sequence-guard (`parseSeq`): `/api/parse` летит по мере набора, предпросмотр рисуется чипсами (место, дата, сбор, бюджет, гости, «не хватает»). Когда `draftComplete`, срабатывает быстрый путь: `createFromDraft` создаёт событие и ведёт сразу на табло, минуя конструктор. Иначе черновик уходит в `sessionStorage` и подхватывается конструктором.

Голосовой ввод работает через Web Speech API (ru-RU, interim results). В конструкторе сидят `amendBar` (правка словами через `/amend`) и `quickParseGuest`: мгновенный regex-парсер строк вида «Паша из Перми, быстрее, с ночёвкой» без LLM. `normalizeCityInput` приводит введённый город к известному из гео-индекса.

## Табло (board.js)

`openStream` открывает `EventSource` на `/api/events/{id}/stream`; событие `board` вызывает `applyBoard`: перерисовка строк, полоса «N/M улыбок в сборе», «цена улыбки» (сумма цен ÷ число гостей с маршрутом), блоки needs_help, волны, попутчиков, тотализатора, обратный отсчёт по `gather_at`.

Смена статуса строки включает split-flap анимацию (класс `flap`). Когда собраны все, один раз запускается `smileRain()` — дождь из смайликов (флаг `_celebrated`).

Действия на табло: копирование join-ссылки и всех приглашений, экспорт ICS, ручной recheck, кнопка «рассыпать» (demo collapse), инлайн-добавление гостя, деталь строки (альтернативы с пином, журнал решений, отели, кнопка «Дожать на Туту»).

## Карта

Mapbox GL, стиль `light-v11`, старт [50, 56] z3.1. Два GeoJSON-слоя (линии и города), цвет по статусу строки, пункт назначения — красная точка. `fitBounds` один раз. Без токена или WebGL показывается заглушка.

## Карточка гостя

Человеческая карточка от LLM, факты маршрута, попутчики с кнопкой согласия «показать моё имя», посадочный талон с QR на `checkout_url`, кнопка «я купил билет» (фриз строки), выбор альтернативы («поеду этим»), per-leg ссылки для сложных маршрутов.

## Рулетка

Плитки интересов (11), scope РФ/заграница/всё, чекбокс безвиза, исключения видов транспорта. Поток двухфазный:

1. `/api/roulette/pool` отдаёт пул мгновенно; барабан крутится ~2.5 с по этому пулу (задержка растёт × 1.14 до 380 мс).
2. `/api/roulette/price` считает победителя и двух запасных параллельно. Если колесо «довернулось» к запасному (`landed ≠ city`), фронт показывает тост и доп-прокрутку. Ошибка переключает на следующий непробованный город.

Карточка результата: плечо до хаба, туда/обратно/отель с чекаутами, виза, теги, `in_budget`. Лента впечатлений грузит фото каскадом Википедии (`wikiSummaryPhoto` → `wikiSearchPhoto` → фото города), клик ведёт в Google Maps. `cityplan` строит пеший маршрут с экспортом в Google Maps как walking-deeplink с waypoints.

## Meet

Два города и интересы → `/api/meet`. Города с `reachable == 2` плывут наверх. Кнопка «собрать здесь» создаёт полноценное событие на двоих (buffer 1 ч, spacing 0) с табло и чекаутами.
