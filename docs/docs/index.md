# Улыбка (tutu-smile)

Сервис собирает гостей события из разных городов к одному дедлайну. Организатор задаёт рамки (место, дата, час сбора), «Улыбка» строит каждому гостю маршрут через живой инвентарь Туту MCP, держит табло прибытий и выдаёт чекаут-ссылки.

Этот сайт документирует исходный код сервиса. ТЗ и продуктовое описание ищите в репозитории (`TZ.md`, `README.md`).

## Факты о кодовой базе

- Модуль `github.com/ma4ypic4y/tutu-smile`, Go 1.26.4.
- Внешних зависимостей нет. Только stdlib; фронт тянет Mapbox GL и qrcodejs с CDN.
- Один бинарник: бэкенд, оркестрация MCP и раздача встроенного фронта (`//go:embed`).
- Хранение в памяти. Аккаунтов и БД нет, карточка гостя живёт по ссылке.

## Запуск

```bash
cp .env.example .env      # OPENROUTER_API_KEY и MAPBOX_TOKEN, оба опциональны
go run ./cmd/smile        # http://localhost:8080
go test ./...             # планировщик, волна, MCP-клиент, парсер LLM
```

Без ключа OpenRouter умный ввод отвечает 503 с пояснением, вайб-режим и человеческие карточки переключаются на детерминированные заготовки. Без Mapbox-токена пропадает карта. Всё остальное работает на живом MCP без ключей.

## Карта документации

- **Архитектура и пакеты**: граф зависимостей, конфиг, модель данных, стор.
- **Конвейер**: как собирается табло. Планировщик, волна обнимашек, попутчики, оркестратор, перепроверки, тотализатор.
- **MCP-клиент и слой tutu**: JSON-RPC, кэш, ретраи, politeness-gate, circuit breaker, прокси, типизированный домен.
- **HTTP API**: все эндпоинты с параметрами.
- **Фронтенд**: hash-роутер, умный ввод, табло на SSE, карта, рулетка.
